# 🎒 Guía del estudiante

1. Lee README y theory.
2. Ejecuta `lab.py`.
3. Trabaja en `notebook_student.ipynb`.
4. Compara con la solución después de intentar el reto.
5. Responde `assessment.md`.
6. Registra ID completado en un archivo de progreso o en la PWA.

No necesitas GPU ni API para las demostraciones centrales. Las extensiones
grandes aparecen como actividades opcionales.
