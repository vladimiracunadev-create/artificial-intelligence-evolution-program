# 🎓 Estándar pedagógico

Cada clase incluye:

1. propósito y ubicación histórica;
2. resultados verificables;
3. teoría con referencias;
4. laboratorio reproducible;
5. notebook guiado;
6. notebook de estudiante;
7. solución de referencia;
8. evaluación y reto;
9. errores comunes y FAQ;
10. límites de aplicación.

## 🔍 Evidencia antes que volumen

Una clase no se considera completa por tener muchos archivos. Debe poder
responder qué aprende el estudiante, qué ejecuta, qué entrega y cómo se verifica.
