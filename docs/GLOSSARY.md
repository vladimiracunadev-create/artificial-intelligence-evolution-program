# 📖 Glosario esencial

- **Agente:** sistema que decide acciones para cumplir un objetivo.
- **Baseline:** referencia mínima contra la que se compara una mejora.
- **Embedding:** representación vectorial aprendida o construida.
- **Eval:** prueba estructurada de comportamiento o calidad.
- **Guardrail:** control que valida o limita entradas, salidas o acciones.
- **Handoff:** transferencia de responsabilidad entre agentes.
- **MCP:** protocolo para conectar aplicaciones de IA con herramientas y contexto.
- **Modelo fundacional:** modelo preentrenado adaptable a múltiples tareas.
- **RAG:** generación apoyada por recuperación de evidencia.
- **Skill:** instrucciones y recursos portables para una capacidad.
- **Tool:** operación invocable con un contrato.
- **Workflow:** secuencia explícita de pasos y decisiones.
