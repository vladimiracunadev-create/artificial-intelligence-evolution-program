# Política de datasets

- No se guardan datasets grandes en Git.
- No se generan datos sintéticos para ocultar una descarga fallida.
- Cada fuente tiene URL, uso y estado de licencia.
- La licencia debe revisarse nuevamente para la versión descargada.
- Los splits oficiales se respetan cuando existen.
- Ajustes, vocabularios y transformaciones se aprenden solo con train.
- Datos sensibles requieren base legal, minimización y controles.

Consulta `datasets/catalog.yaml`.
