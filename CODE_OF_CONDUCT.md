# 🤝 Código de conducta

Este proyecto exige colaboración respetuosa, crítica basada en evidencia y
reconocimiento de límites. No se toleran acoso, discriminación, publicación de
datos personales ni uso de los laboratorios para perjudicar a terceros.

Los ejemplos de seguridad, vigilancia, identidad y automatización deben usarse
solo con autorización y dentro de la ley aplicable.
